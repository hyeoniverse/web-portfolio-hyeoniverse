# UI Components & Interaction

Built the core UI components — **Hero** section, **Navigation**, **Contact Drawer**, and **Loading Screen**. Their motion runs on **GSAP** and **Framer Motion**: Image Velocity, StaggerText, Mouse Parallax, and Magnetic Hover. Each responds to scroll speed and pointer movement with **spring damping**, so values converge on their target and settle instead of snapping.
