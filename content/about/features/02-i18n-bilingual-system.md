# i18n Bilingual System

한국어·영어를 즉시 전환하고, 글·작업물·프로필도 두 언어로 저장합니다. 비어 있는 언어 칸은 DeepL·Google·Gemini·Claude 를 설정한 순서대로 시도해 자동 번역하고, 원문을 고치면 다시 번역합니다. 메뉴의 🌐 단추로는 사이트 전체를 33개 언어 중 하나로 바꿔 볼 수 있고, 번역은 언어마다 한 번 만들어 저장합니다.
