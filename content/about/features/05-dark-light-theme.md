# Dark / Light Theme

색은 역할 토큰 안의 `light-dark()` 와 `color-scheme` 으로 정해, 다크·라이트를 바꾸면 모든 요소가 한 번에 바뀝니다. 전환은 View Transitions 로 이어지고, 움직임 줄이기를 켜면 바로 바뀝니다. 시스템 설정을 따르다가 사용자가 고르면 그 선택을 기억합니다.
