# Admin CMS

URL 로 직접 들어가는 숨겨진 어드민입니다. 포스트·작업물·프로필을 이중 언어로 관리하고, 테마·폰트·브랜드 설정을 바로 바꿉니다. 트래픽 페이지에서 유입 채널·기기·국가·UTM·재방문 IP 를 봅니다. 번역·요약·TTS 같은 외부 서비스는 실패 원인을 가려 알리고, 같은 원인으로 이어 실패하면 그 공급자를 꺼 두며, 이번 달 사용량과 호출 기록을 한 화면에서 봅니다. DB 에 연결되지 않으면 정적 데이터로 돌아갑니다.
