# Admin CMS

A hidden admin reached by direct URL. Posts, works, and profiles are managed in two languages, and theme, font, and brand settings change instantly. The traffic page shows referral channels, devices, countries, UTM campaigns, and returning IPs. Without a database it falls back to static data.
