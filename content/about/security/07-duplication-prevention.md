# 중복 방지 · IP 최소 보관

좋아요는 `(대상, IP)`, 투표는 `(투표, 선택지, IP)` **UNIQUE 인덱스**로 DB 에서 중복을 막습니다. 조회 · 방문은 조회 기록(`page_views`) 하나에 남기고, 같은 IP 가 같은 페이지를 **30분 안에** 다시 보면 앞 기록을 돌려줍니다. 동시 요청은 advisory lock 으로 줄 세웁니다. 원문 IP 는 응답에 싣지 않고 가려서 보여 주며, 조회 기록의 IP 는 90일 뒤 비웁니다. 운영자가 지정한 IP 는 기록하지 않습니다.
