# 에디터 · 마크다운 문법 가이드

이 프로젝트에는 두 종류의 에디터가 있고, 지원하는 문법이 조금 다르다.

- **글 에디터** — Plate(Slate 기반) WYSIWYG. 마크다운을 입력하면 그 자리에서 서식으로 바뀌고(autoformat), 슬래시(`/`)·멘션(`@`·`[[`)·이모지(`:`) 트리거와 리치 블록(투표·달력·다이어그램 등)을 지원한다. 서식은 툴바·단축키로도 넣을 수 있다.
- **댓글 에디터** — 경량 마크다운. 작성한 마크다운 문자열을 `marked` 로 렌더한다(작성 / 미리보기 탭). 비신뢰 입력이라 렌더 결과는 DOMPurify 화이트리스트로 정화된다(스크립트·임의 HTML 차단).

> 실시간 도움말: 글 에디터는 우측 상단 **도움말(?)** 버튼(단축키·문법), 댓글은 툴바의 **"마크다운 지원"** 버튼에 같은 내용이 들어 있다.

## 인라인 서식

| 문법 | 결과 | 글 에디터 | 댓글 |
|---|---|:---:|:---:|
| `**굵게**` | **굵게** | 자동변환 · `Cmd+B` | ✓ |
| `*기울임*` | *기울임* | 자동변환 · `Cmd+I` | ✓ |
| `***굵게+기울임***` | ***굵게+기울임*** | — | ✓ |
| `~~취소선~~` | ~~취소선~~ | 자동변환 · `Cmd+Shift+S` | ✓ (선만 accent) |
| `==형광==` | 형광펜 | 자동변환 | `<mark>형광</mark>` |
| `` `코드` `` + Space | `코드` | 자동변환 · `Cmd+E` | ✓ |
| 밑줄 | 밑줄 | `Cmd+U` | `<ins>밑줄</ins>` |
| 위첨자 | X² | 툴바 | `<sup>2</sup>` |
| 아래첨자 | X₂ | 툴바 | `<sub>2</sub>` |
| 키 입력 | `Ctrl` | — | `<kbd>Ctrl</kbd>` |
| `[텍스트](url)` | 링크 | 자동변환 | ✓ |
| `![설명](url)` | 이미지 | 자동변환 | ✓ (외부 URL만) |
| `:tada:` | 🎉 | 자동변환 | ✓ |

**인라인 코드의 특별한 동작** (글·댓글·리더 공통)
- **문법 하이라이트** — 명확히 코드로 추론되는 인라인 코드는 자동으로 syntax highlight 된다. 짧은 것(≈12자 미만)·색상값·비코드는 평문 유지.
- **색 스와치** — 내용이 `#hex`·`rgb()`·`hsl()` 색상값이면 앞에 색 원(스와치)이 붙는다(GitHub 스타일).
- **스타일** — Notion 식 배경형: 보더 없이 은은한 배경 + accent 텍스트, 양끝만 캡슐. 길면 여러 줄로 자연스럽게 줄바꿈된다.
- **입력(글 에디터)** — `` ` `` 쌍을 친 뒤 **스페이스**를 눌러야 변환된다(즉시 변환 아님). 인라인 코드 바로 뒤에서 **백스페이스**를 누르면 내용이 지워지는 게 아니라 **코드가 해제**된다(백틱 제거).

## 블록

| 문법 | 결과 | 글 에디터 | 댓글 |
|---|---|:---:|:---:|
| `#` ~ `######` + Space | 제목 1~6 | 자동변환 · `Cmd+Opt+1/2/3` | ✓ |
| `>` + Space | 인용문 | 자동변환 · `Cmd+Shift+B` | ✓ |
| `-` / `1.` + Space | 불릿 / 번호 목록 | 자동변환 · `Cmd+Shift+8/7` | ✓ |
| `[]` + Space | 체크박스(할 일) | 자동변환 | `- [ ] 할 일` |
| ```` ``` ```` + Enter | 코드 블록 | 자동변환 | ```` ```js ```` |
| `---` | 구분선 | 자동변환 | ✓ |
| `\| a \| b \|` | 표 | 툴바(표 블록) | ✓ |
| `> [!NOTE]` | 알림 콜아웃 | 자동변환 | ✓ |
| `[^1]` | 각주 | 자동변환 | ✓ |

**알림(Alert / Callout)** — `> [!TYPE]` 뒤에 내용. `TYPE` 은 `NOTE` · `TIP` · `IMPORTANT` · `WARNING` · `CAUTION` 5종이며 타입별 아이콘·색이 붙는다. 글 에디터에선 `[!NOTE]` 를 치고 `]` 를 누르면 콜아웃 블록으로 감싸진다.

```
> [!WARNING]
> 되돌릴 수 없는 작업입니다.
```

**각주** — 본문에 `[^1]`, 문서 끝에 `[^1]: 각주 내용`. 글 에디터는 `[^라벨]` 입력 시 각주 참조 + 문서 끝 각주 내용 블록을 자동으로 만든다.

**코드 블록** — 언어를 적으면 syntax highlight 된다(Prism). 리더/미리보기에서 코드 블록 위에 언어 라벨 + 복사·줄바꿈 토글 버튼이 붙고, 코드블록 위에서 세로로 스크롤하면 페이지로 자연스럽게 넘어간다(축 기반 wheel 라우팅).

## 글 에디터 전용 트리거 · 리치 블록

| 트리거 | 동작 |
|---|---|
| `/` | 슬래시 메뉴 — 모든 블록 삽입 |
| `@` | 날짜 멘션 — 오늘 · 내일 · 날짜 선택 |
| `:` | 이모지 피커 (`:키워드` 로 인라인 검색) |
| `[[` | 게시물 링크 — 다른 글을 검색해 내부 링크 pill 삽입 |

**리치 블록** (슬래시 메뉴 / 툴바): 투표(poll), 달력(calendar), 다이어그램·mermaid, 탭(tabs), 토글(toggle), 수식(KaTeX), 코드 플레이그라운드(Sandpack), 이미지, 열(column), 커스텀 이모지.

**색상** — 툴바 색상 피커로 글자색·배경색을 지정한다(최근 쓴 색 기억). 댓글은 색상 버튼으로 색을 고르면 `` `#hex` `` 인라인 코드로 삽입되고, 색 스와치로 렌더된다.

**게시물 링크(댓글)** — 댓글 툴바의 게시물 링크 버튼으로 다른 글을 검색해 `[제목](/posts/slug)` 상대 링크를 꽂을 수 있다(새 창으로 열림).

## 주요 단축키 (글 에디터)

| 동작 | 단축키 |
|---|---|
| 굵게 · 기울임 · 밑줄 · 취소선 · 코드 | `Cmd+B` · `I` · `U` · `Shift+S` · `E` |
| 제목 1 / 2 / 3 | `Cmd+Opt+1 / 2 / 3` |
| 인용문 | `Cmd+Shift+B` |
| 불릿 / 번호 목록 | `Cmd+Shift+8 / 7` |
| 실행 취소 / 다시 실행 | `Cmd+Z` / `Cmd+Shift+Z` |
| 블록 간 이동(커서) | `Opt+↑ / ↓` |
| 블록 이동 | `Cmd+Opt+Shift+방향키` |
| 블록 선택 | `Shift+↑ / ↓` · `Shift+Click` |

Windows·Linux 는 `Cmd → Ctrl`, `Opt → Alt` 로 매핑된다.

## 댓글 렌더 파이프라인

댓글은 `marked`(gfm + breaks + alert + footnote + emoji 확장) → DOMPurify 정화 순서로 렌더된다. 허용 태그·속성 화이트리스트 밖의 HTML(스크립트, 이벤트 핸들러, 임의 태그)은 제거된다. 이미지는 외부 `http(s)` URL 만 통과하며, 게시물 내부 링크(`/posts/...`) 같은 루트 상대경로는 허용하되 프로토콜 상대 URL(`//...`)은 차단한다.
