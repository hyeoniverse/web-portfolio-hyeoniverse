# 편집 화면 UI 원칙

관리자 편집 화면(작업물 · 글)을 짤 때 따르는 규칙이다. 값(색 · 간격 · 크기 토큰)은 [디자인 시스템 명세](./design-system.md)가 정하고,
이 문서는 그 값으로 **화면을 어떻게 짜는지**를 정한다. 새 칸 · 새 구획을 더할 때도 이 순서로 고른다.

## 1. 분위기 — 공개 화면에서 온다

편집 화면은 공개 화면을 만드는 곳이라, 공개 화면과 같은 결이어야 한다. 공개 화면의 결은 이렇다.

- **종이와 먹.** 크림 바탕 위의 먹색 글자. 강조색(마젠타)은 점 하나 · 밑줄 하나 정도로만 쓴다.
- **상자 대신 선과 여백.** 구획은 전체 폭의 가는 선과 여백으로 나눈다. 채운 면(카드)은 거의 없다.
- **라벨 아래 값.** 작은 옅은 라벨 아래에 값을 글처럼 적는다(작업물 상세의 `YEAR / 2026`).
- **고르는 것은 알약, 탭은 밑줄.** 칩 · 단추는 얇은 테두리 알약, 탭은 고른 것만 밑줄(글 목록의 분류).
- **제목은 세리프로 크게.** 나머지 글은 담백하게.

## 2. 원칙

**2-1. 적는 칸은 밑줄, 고르는 것은 알약.**
글자를 적는 칸(한 줄 입력 · 여러 줄 입력)은 아래 선 하나(`variant="underline"`)로 그린다. 적은 값이 공개 화면의 "라벨 아래 값"처럼 읽힌다.
고르거나 누르는 것(셀렉트 · 단추 · 칩 · 검색 선택)은 알약 그대로다. 그래서 "어디에 적고 어디를 누르는지"가 모양만으로 갈린다.
— 아래 선은 입력 경계라 대비 3:1 인 `--border-color-control` 이다(명세 3.6-3). 초점이 오면 `--text-primary` 로 진해진다.

**2-2. 상자 안에 상자를 두지 않는다.**
면(바탕을 채운 판 · 테두리 상자)은 한 겹까지만. 화면 위에 뜨는 것(팝오버 · 메뉴 · 드로어)만 면을 가진다.
목록의 한 줄을 고칠 때는 판이나 표시선을 따로 두지 않고, **그 줄 자리에서 폼이 열린다**(얼굴 · 이름의 자리를 그대로 이어받는다).

**2-3. 위계는 세 단계.**

| 단계 | 쓰임 | 글자 |
|---|---|---|
| 제목 | 글 · 작업물 제목 입력 | `--font-headline-xl`(세리프) |
| 구획 이름 | 본문 · 이미지 · 추가 정보 · 속성 | `--font-label-md`, `--text-secondary` |
| 칸 이름 | 부제 · slug · 이메일 … | `--font-label-sm`, `--text-secondary` |

값은 `--font-body-md` · `--text-primary`, 도움말은 `--font-body-sm` · `--text-tertiary`. 대문자 변환은 쓰지 않는다(영문 라벨만 커진다).

**2-4. 간격은 다섯 단계 리듬.**

| 사이 | 값 |
|---|---|
| 칸 이름 → 칸 | `--spacing-8` |
| 같은 줄의 칸 · 단추 | `--spacing-8` (묶음과 묶음 사이는 `--spacing-16`) |
| 칸 → 칸 | `--spacing-24` |
| 묶음 → 묶음 (구획 안) | `--spacing-40` |
| 구획 → 구획 | `--spacing-64`, 사이에 전체 폭 가는 선 |

간격은 이 다섯 중에서 고른다. 사이 값을 새로 만들지 않는다.

**2-5. 크기는 정해진 것만.**
컨트롤 높이 32(`md`), 칩 · 본문 도구 막대 28(`sm`), 아이콘 단추 32 정사각. 아이콘은 컨트롤 안 14, 머리 16.
얼굴(아바타)은 목록 32, 사진을 올리는 폼 48, 칩 안 18.

**2-6. 폭은 내용만큼.**
짧은 값(slug · 이메일 · 주소)도 열 폭을 채우되, KO · EN 처럼 짝인 칸은 두 칸으로 나란히. 한 줄에 서로 다른 칸을 세 개 넘게 두지 않는다.

**2-7. 강조색은 뜻이 있을 때만.**
필수 점 · 고른 것의 표시 · 경고(음성이 대본보다 낡음)만. 안내 글 · 장식에는 쓰지 않는다. 주 동작(저장)은 먹색 바탕이다.

**2-8. 동작은 그것이 다루는 것 끝에.**
폼의 저장 · 취소는 폼 아래 오른쪽, 줄의 편집 · 빼기는 줄 오른쪽 끝. 동작만 모은 줄을 내용 위에 따로 두지 않는다.

**2-9. 비었을 때는 한 줄과 동작 하나.**
`--text-tertiary` 한 줄로 비었다고 알리고, 채울 동작(추가 단추)을 하나 둔다.

**2-10. 단추는 세 가지뿐.**
칸 옆 · 폼 아래의 작은 동작은 모두 높이 28(`sm`), 글자 `--font-label-sm`, 아이콘 14 — 공용 클래스 `adminEditorStyles.toolBtn*`.

| 종류 | 쓰임 | 모양 |
|---|---|---|
| 보조 | 업로드 · 고르기 · 새 팀원 추가 · 계정 연결 · 취소 | 옅은 테두리 알약 + 먹색 글자(`toolBtn`, `variant="ghost"`) |
| 지우기 | 커버 제거 등 | 보조와 같고, 올리면 강조색(`toolBtn toolBtnDanger`) |
| 주 동작 | 폼의 저장 · 추가 | 먹색 바탕(`variant="primary"` + `toolBtnPrimary`) |

상단 막대의 미리보기 · 임시저장 · 저장(32)과 아이콘 단추는 막대의 크기를 따른다.
